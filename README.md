# About The Project
I have built this portfolio website to showcase my hardware projects, AI experiments, coding work, and creative tech ideas. It highlights my journey as a student developer and creator passionate about building innovative products and learning new technologies.

This website represents my interest in combining creativity with technology to build projects that are both useful and visually engaging. From custom mechanical macropads and PCB designs to AI-powered ideas and software experiments, I enjoy exploring different areas of engineering and digital creation.

Through this portfolio, I want to share my projects, skills, experiences, and future goals while continuously improving as a developer, designer, and problem solver. Every project here reflects my curiosity, learning process, and passion for building new things.

This portfolio template can also be used by other students, developers, creators, and tech enthusiasts who want to build a modern and attractive personal portfolio website. Users can customize the design, projects, skills, colors, and content based on their own style and needs.

# Features
Modern and attractive UI
Fully responsive design
Project showcase section
Skills and experience section
Smooth animations and clean layout
Customizable portfolio template

Beginner-friendly structure

# AI Usage
I used AI tools occasionally for brainstorming design ideas, improving some content writing, and getting suggestions for the overall layout of the portfolio website. Most of the customization, project setup, and development work was done manually by me.

# Customization
Users can easily customize:

Colors and themes
Project cards
Skills section
About section
Social links
Animations and layout
Personal branding
This makes the website a reusable portfolio template for anyone wanting a creative and professional online presence.
